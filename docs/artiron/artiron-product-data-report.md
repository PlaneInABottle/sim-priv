## Pricing Model Notes

### Pricing Structure
- **ALL main products** (plise perdeler, sineklikler, honeycomb kapılar, stor perdeler, jaluziler): **Fiyat m² üzerinden hesaplanır**
  - Shown text: *"Fiyat m² üzerinden hesaplanır. En/Boy değerleri sipariş notu olarak değerlendirilir"*
  - Customer enters **En (cm)** and **Boy (cm)** → system calculates **Alan (m²)** → price is computed
  - The displayed price on the product page is the **base per-m² rate**
- **Accessories**: Fixed price per piece (not per m²)

### Discount Campaigns (Site-wide)
| Campaign | Type | Applies To |
|----------|------|-----------|
| SEPETTE %5 İNDİRİM | Otomatik sepet indirimi | Tüm ürünler |
| 10 adet ve üzeri siparişlerde %5 indirim | Miktar indirimi | Tüm ürünler |
| 20 adet ve üzeri siparişe %10 indirim | Miktar indirimi | Tüm ürünler |

### Installment Options (Taksit)
All products support credit card installments up to 12 taksit.
Some products advertise "Peşin fiyatına 3 taksit" (3 installments at cash price).

### Shipping

### Pencere vs Kapı Thresholds

| **KLEMP Sineklik** | — | — | — | ₺1,600/m² |

### Routing Logic for WhatsApp Agent

```
IF sineklik isteniyor:
  IF en > 70 cm OR boy > 140 cm:
    → Kapı Sürme Sineklik (max 90×210)
  ELSE IF menteşeli isteniyorsa:
    → Menteşeli Sineklik (max 70×130)
  ELSE IF vidasız/klemp isteniyorsa:
    → KLEMP Sineklik
    → ⚠️ PVC damlalik uyumluluk kontrolü için WhatsApp görsel iste
  ELSE IF çift açılır / geniş açıklık:
    → DOUBLE Sineklik
  ELSE:
    → Pencere Sürme Sineklik (max 70×140)

IF perde isteniyor:
  IF tam karartma / mahremiyet:
    → Blackout Serisi (₺900/m²)
  ELSE IF ısı yalıtımı:
    → Honeycomb Plise (₺1,300/m²)
  ELSE IF gece/gündüz / tül+kumaş:
    → Çiftli Sistem (₺900/m²)
  ELSE IF çocuk odası / baskılı:
    → Baskılı Plise (₺799/m²)
  ELSE:
    → Düz Renk Plise (₺450/m²)

IF kapı perdesi / seperatör:
  → Honeycomb Kapı (₺2,000/m²)

IF stor perde:
  → Kalın Keten Stor Perde (₺300/m²)

IF jaluzi perde:
  → Ahşap Jaluzi 50mm (₺2,100/m²)
```

### DUBLE (Double) Sineklik Rules
- Used for **wide openings** where a single panel isn't enough
- **Çift açılır** = opens from both sides
- Same profile as kapı sineklik (27×40 mm)
- Profile colors: Beyaz, Antrasit, Altın Meşe

### Specialty Products
- **Kedi sinekliği**: KLEMP Sineklik has "kedilerin çizilmesine dayanıklı" ağ seçeneği
- **Cam balkon**: All Plise Perde products are cam balkon uyumlu (14 mm kumaş genişliği)
- **Ofis**: Same plise perde products used for office applications
